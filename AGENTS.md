# AGENTS.md

## Product invariant

Chat is the primary operating surface. Do not move the critical estimating flow into a disconnected dashboard or legacy portal.

## Execution order

1. Understand the construction task.
2. Create a technology card before estimate lines.
3. Show assumptions and missing data.
4. Build deterministic estimate arithmetic.
5. Never invent official norms, indices, codes, sources, or prices.
6. Run an independent review.
7. Render every domain artifact as assistant-ui tool UI in the same thread.
8. Persist every mutation as a new immutable revision.

## Technical invariants

- One transport: AG-UI over `POST /api/agent`.
- Never expose provider secrets to browser events, localStorage, logs or repository.
- Never expose chain-of-thought; use safe work trace only.
- Tenant id must scope every server query.
- Production cannot silently fall back to fixtures.
- Red gates block deployment.
