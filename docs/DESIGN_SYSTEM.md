# Дизайн-система Prosmet Greenfield

## Характер

Лаконичный, спокойный, профессиональный assistant-first продукт. Визуальная логика близка к современным Codex/GPT-like рабочим пространствам, но компоненты и композиция оригинальны.

## Цвет

- Canvas: `#ffffff`
- Secondary canvas: `#f7f7f8`
- Sidebar: `#f4f4f5`
- Primary text: `#171719`
- Secondary text: `#6f7176`
- Border: `rgba(23, 23, 25, 0.10)`
- Primary action: `#171719`
- Success: `#177245`
- Warning: `#9a6700`
- Danger: `#b42318`

Зелёный не является фирменной заливкой интерфейса и используется только как семантический success-status.

## Типографика

Системный sans-serif stack. Desktop body 14–16 px. Mobile body не меньше 16 px. Заголовки короткие, без декоративных eyebrow/pill-элементов.

## Контейнеры

Не использовать вложенные card-grid и декоративные панели. Основные формы: открытый canvas, sidebar, rail, список, документ, bottom sheet.

## Desktop

- Sidebar 252 px.
- Центральный чат до 820 px с большим свободным пространством.
- Результат открывается отдельным рабочим слоем, а не маленькой карточкой поверх чата.
- Редактор документа: основной лист + summary rail 296 px.

## Mobile

- Отдельный top bar.
- Нижняя навигация 72 px + safe area.
- Touch target не меньше 48 px.
- Карточка позиции сметы не меньше 112 px.
- Итог и primary action закреплены у нижнего края.
- Таблица desktop на mobile не уменьшается, а заменяется карточками.
