# Архитектура Greenfield V3

## Принцип

Пользователь видит одно универсальное приложение. Конкретная отрасль, агент и набор инструментов подключаются конфигурацией, а не прошиваются в shell.

```text
Web / iOS / Android / Tauri
          │
   assistant-ui runtime
          │
      Agent Adapter
          │
  AG-UI / A2A / Codex / OpenAI-compatible / локальный агент
          │
  Application API + PostgreSQL
          │
  Rust calculation authority
```

## Границы ответственности

- UI отвечает за навигацию, диалог, редактирование и подтверждение действий.
- Agent adapter отвечает за streaming и преобразование событий провайдера.
- Сервер хранит пользователей, организации, проекты, версии и документы.
- Rust-движок выполняет детерминированные расчёты и не доверяет AI итоговые суммы.
- Mobile имеет собственную компоновку и не использует desktop DOM/CSS.

## Миграция

В новый проект разрешено переносить только:

- схемы данных;
- API-контракты;
- миграции базы после отдельной проверки;
- Rust-формулы и контрольные тесты;
- протоколы agent adapters.

Запрещён перенос старых React-компонентов, страниц, CSS, layout и визуальных тестов.
